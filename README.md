# online-hospital-management-system
Backend project for Online Hospital Management System using Node.js and Express
## Technologies Used
- Node.js
- Express.js
- MongoDB
- REST APIs

## Features
- Patient Registration
- Doctor Management
- Appointment Booking
- Hospital Data Management
